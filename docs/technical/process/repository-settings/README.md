# Repository settings

The GitHub configuration the workflow in
[CONTRIBUTING.md](../../../../CONTRIBUTING.md) assumes.

**Recorded here because settings live in a web UI where nobody can review
them** — a change that quietly weakens a protection leaves no trace otherwise.

| | |
|---|---|
| [`access.md`](access.md) | Who can do what, and the repository-wide switches |
| [`protection.md`](protection.md) | Branch protection on `main`, and the `v*` tag ruleset |
| [`actions.md`](actions.md) | Fork workflow approval, token permissions, and why there are no secrets |
| [`cla-bot.md`](cla-bot.md) | How the CLA is enforced, and the setup that is still open |

- A change to these settings is a change to the project's guarantees: it updates the file here in the same PR, and states the reason.
