# Site

The landing page — the one surface that is not the app.

- `landing-dark.svg` is the page; `site.pdf` is the card around it.
- It draws from the same palette, type scale and masters as the app. A product whose site looks like a different product has told on itself before anyone downloads it.
- **Only the dark theme is drawn.** The site does not follow the reader's system setting, so it was designed once, in the theme the brand reads best in.
- Nothing here is built. The site is out of the MVP ([roadmap](../../roadmap.md)); the board exists so the identity is decided in one place rather than twice ([brand/](../brand/README.md)).
