# Penpot backlog

What the Penpot file still owes, and where each of its pages is exported.

- **The export happens only when the maintainer asks for it.** It is slow and it locks the file, so it is never a step of building a feature.
- A screen is approved in Penpot before its code is written, and exported before the change that builds it merges.
- **Every page below was exported after the last board changed** — a board drawn or changed after that export is not on disk until the next one.
- Only boards are exported, both themes, as SVG. A page's card is not exported, and neither is the `Prototypes` page.
- **Before any write:** `penpot.currentFile.name` is `TOM` and `penpot.currentPage.name` is the page meant. Never write and `openPage` in the same call.
- **After an export:** run [`embed_fonts.py`](tools/embed_fonts.py), then `grep -L "data:font"` over the folder and export again whatever it lists.
