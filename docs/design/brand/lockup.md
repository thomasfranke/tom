# The lockup

Icon and wordmark side by side.

- The icon at 128, a 36px gap, the wordmark at cap 80 — which puts the trunk's reach close to the tile's edges, so the two read as one height.
- Use it where both are wanted: a README header, a website.
- **Not inside the app**, where the icon is already on the dock and the wordmark alone is enough.
