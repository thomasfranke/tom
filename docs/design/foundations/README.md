# Foundations

The library page as drawn: the colour roles as swatches, the type scale in its
own faces, and the radius and elevation steps.

- Both themes, `foundations-light.svg` and `foundations-dark.svg`; the card around them is read in the Penpot file and is not exported.
- This page holds no component; the masters and the specimens are [`components/`](../components/README.md)'s pages, and why they are kept apart is [`library.md`](../components/library.md).
- This folder is the picture, not the specification — the numbers are in [`components/`](../components/README.md), the reasoning behind the roles in [`visual-language/`](../visual-language/README.md). A colour picked off a screenshot is a colour that drifts.
