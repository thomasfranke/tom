# Masters no screen asks for

| Master | Why it exists anyway |
|---|---|
| `Fab` · `Radio` · `Slider` | No screen asks for them; drawn so the set is complete |
| `Switch` | Wanted only by Settings in M3 |
| `Panel toggle`, bottom variants | The bottom strip is coming, and the control is drawn for it |

They exist so nobody invents a fourth kind of toggle later. They are **not** a
commitment that the product will use them, and a master here is not a reason to
put one on a screen.
