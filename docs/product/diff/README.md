# Diff

What changed, drawn over the *formatted* document rather than over raw markdown
— the product's core differentiator.

**Status:** Shipped · Milestone M2

Both features are the same reading. They differ only in what the document is
compared against: the working tree against its last commit, or the document
against a branch or a commit somebody chose.
