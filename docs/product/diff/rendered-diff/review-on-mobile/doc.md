# Review, on mobile

The mobile counterpart of the rendered diff, for someone who is rarely at a desk
when review happens.

**Status:** Exploratory · Phase 3, post-1.0

## Rules

- Changes are shown rendered, the same principle as desktop — never as raw text.
- **Approving is the one action on this screen.**
- Block granularity depends on the same open question as desktop (Spike B).

Not drawn. Mobile is drawn from the job rather than from the desktop layout
([Decision 8](../../../../technical/decisions/008-monorepo-with-pure-dart-core.md))
and waits on the two questions the [roadmap](../../../../roadmap.md#phases)
names.
