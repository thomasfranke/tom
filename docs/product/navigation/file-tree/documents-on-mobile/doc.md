# Documents, on mobile

The mobile counterpart of the tree, which on a phone is the first screen rather
than a sidebar.

**Status:** Exploratory · Phase 3, post-1.0

## Rules

- **The document list is the entry screen.** There is no separate sidebar.
- Opening a document pushes onto a navigation stack; there is no split view.
- The list can be filtered by typing, without leaving the screen.

Not drawn. It assumes a space is already open — how one is chosen on a phone in
the first place is [home](../../../home/README.md)'s open question.
