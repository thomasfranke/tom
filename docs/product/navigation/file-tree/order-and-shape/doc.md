# Order and shape

How rows are sorted, and where the tree sits.

**Status:** Planned · Milestone M0

## Rules

- **Folders come before files at every level**, each group in name order. A folder is a place to go and a file is a thing to open, so the two never interleave.
- Folders open and close, and a space opens with them open: what it holds is visible without a click.
- The chevron is the same one the search uses to open replace, at 16, aligned by its ink rather than its box ([icons](../../../../design/components/icons.md)).
- The tree's width and position stay the same across every screen the app shows ([regions](../../../workspace/regions/doc.md)).
