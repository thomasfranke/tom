# The message

Every commit carries one, and the box is not taken away lightly.

**Status:** Planned · Milestone M1

## Rules

- **A commit requires a message.** Committing with nothing staged is disabled.
- **The message box is never taken away because git is working.** Working on something else is not a reason to interrupt a sentence, and a message typed while it was working is not lost when the answer comes back.
- **One thing does displace it: a push standing refused**, which has to be dealt with before another commit means anything. What was typed is kept and comes back with the band, rather than being emptied.
