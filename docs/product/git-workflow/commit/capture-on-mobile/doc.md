# Capture, on mobile

The mobile counterpart of a commit: a short note and a message, not a document
editor.

**Status:** Exploratory · Phase 3, post-1.0

## Rules

- Capture is a short note plus a commit message. **Authoring a document on a phone is not a goal.**
- The commit happens in one gesture; there is no separate staging step.

Depends on git working without a system binary on iOS/Android, still an open
question —
[Decision 2](../../../../technical/decisions/002-git-via-system-binary.md) names
`libgit2` via FFI as the trigger. Not drawn.
