# Full-text search

Find a document by its contents, not just its file name, across the whole space.

**Status:** Planned · Milestone M2

## Rules

- Search covers the text content of every markdown file in the space, not just file and folder names.
- Results are available offline and return quickly enough to type-ahead — search never depends on the network.
- The search index is a cache: deleting it and reopening the space rebuilds it from the files on disk, with no loss of information.
