# Formatting shortcuts

Buttons and keyboard shortcuts that insert markdown syntax, without hiding the source underneath it.

**Status:** Planned · Milestone M3

## Rules

- Shortcuts and buttons exist for the common cases: bold, italic, list, link.
- Using a shortcut inserts the literal markdown syntax into the source — the source stays visible and remains the truth, never a hidden intermediate format.
